# Customer-trends-data-analysis
A complete data analytics portfolio project with end to end standard data analysis of customer shopping trends from retail using SQL, Python, and Power BI
# Data Analytics Project

## 1. Overview

This project demonstrates an end-to-end data analytics workflow, transforming raw data into meaningful business insights through data exploration, cleaning, SQL analysis, and visualization. The project covers the complete analytics process, from loading and preparing a dataset in Python to querying data using SQL, building an interactive Power BI dashboard, and presenting findings through a written report and presentation.

**Project Objectives:**
- Explore and understand the dataset.
- Perform Exploratory Data Analysis (EDA).
- Clean and prepare data for analysis.
- Use SQL to answer business-related questions.
- Build an interactive Power BI dashboard.
- Communicate key findings through a report and presentation.

## 2. Dataset

The project uses a structured dataset containing information relevant to the business problem being investigated.
The dataset is initially loaded into Python for inspection, exploration, and preprocessing before being used for further analysis.

**Dataset preparation includes:**
- Understanding the dataset structure.
- Examining data types and summary statistics.
- Identifying missing values and duplicate records.
- Checking for inconsistencies and incorrect data formats.
- Preparing clean data for SQL analysis and visualization.

## 4. Project Workflow

The project follows a structured analytics workflow.

### Step 1: Data Loading and Exploration
- Import the dataset into Python.
- Examine the number of rows and columns.
- Review column names, data types, and sample records.
- Generate descriptive statistics to understand the data.

### Step 2: Exploratory Data Analysis (EDA)
- Analyze distributions and patterns within the dataset.
- Identify relationships between variables.
- Investigate trends and potential outliers.
- Create visualizations to support initial findings.

### Step 3: Data Cleaning and Preparation
- Handle missing and duplicate values.
- Correct inconsistent data formats.
- Rename columns where necessary.
- Validate data types and remove inconsistencies.
- Prepare the dataset for database analysis.

### Step 4: SQL Analysis
- Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
- Write SQL queries to extract relevant information.
- Perform aggregations and calculations.
- Use filtering, grouping, joins, and subqueries where appropriate.
- Answer business questions using SQL.

### Step 5: Power BI Dashboard
- Connect Power BI to the cleaned dataset or SQL database.
- Create relevant KPIs and visualizations.
- Develop interactive filters and slicers.
- Design a dashboard that communicates important trends and findings.

### Step 6: Reporting and Presentation
- Document the analytical process and methodology.
- Summarize important findings and business insights in a written report.
- Use Gamma to create a professional presentation highlighting the project's objectives, analysis, visualizations, and conclusions.

## 5. Dashboard

The Power BI dashboard provides a visual summary of the analysis, allowing users to explore key metrics, identify trends, and understand patterns within the dataset.

**Dashboard Features:**
- Key Performance Indicators (KPIs).
- Interactive charts and visualizations.
- Filters and slicers for data exploration.
- Business trends and performance summaries.
- Data-driven insights to support decision-making.

**Project Deliverables:**
- Cleaned dataset.
- Python notebook containing EDA and data cleaning.
- SQL scripts containing analytical queries.
- Interactive Power BI dashboard.
- Written analytical report.
- Gamma presentation summarizing the project.
